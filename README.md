## 🏆 Nobel Prize Dashboard – Power BI

## 📌 Project Overview

This project develops an interactive **Nobel Prize Dashboard** in **Microsoft Power BI** to explore and analyse Nobel Prize data.

The dashboard provides insights into Nobel Prize awards across categories, countries, and years, highlighting patterns and trends in Nobel Prize history.

## 🎯 Project Objectives

* Analyse the distribution of Nobel Prizes across different categories.
* Explore award trends over the years.
* Examine the geographical distribution of Nobel Prize laureates.
* Identify patterns in Nobel Prize awards.
* Present historical data through interactive visualisations.

## 🛠️ Tools Used

* **Microsoft Power BI:** Dashboard development and data visualisation.
* **Microsoft Excel:** Data preparation and cleaning.

## 📈 Key Dashboard Features

* Nobel Prize distribution by category.
* Analysis of award trends over time.
* Country-based analysis.
* Interactive visualisations.
* Historical award patterns.

## 💡 Skills Demonstrated

* Data Cleaning and Preparation
* Data Analysis
* Data Visualisation
* Dashboard Development
* Data Storytelling
* Power BI

## 📝 Conclusion

The Nobel Prize Dashboard demonstrates how historical data can be transformed into meaningful visual insights through interactive reporting and data visualisation.
